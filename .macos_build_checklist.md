# macOS Build Checklist

Use this checklist when building on an actual macOS ARM machine.

## Pre-Build Checklist

- [ ] Running macOS 11 (Big Sur) or later
- [ ] Apple Silicon Mac (M1/M2/M3) or Intel Mac
- [ ] Xcode Command Line Tools installed
  ```bash
  xcode-select --install
  xcode-select -p  # Should show path
  ```
- [ ] CMake 3.22+ installed
  ```bash
  cmake --version  # Should show 3.22 or higher
  brew install cmake  # If not installed
  ```
- [ ] Repository cloned
  ```bash
  git clone https://github.com/pritezza/PRIResonanceSuppressor.git
  cd PRIResonanceSuppressor
  ```

## Build Process Checklist

- [ ] JUCE framework cloned
  ```bash
  ls external/JUCE  # Should exist
  # If not:
  git clone --depth 1 --branch 8.0.16-security \
    https://github.com/juce-framework/JUCE.git external/JUCE
  ```
- [ ] Build script is executable
  ```bash
  chmod +x build_macos_arm.sh install_macos.sh
  ```
- [ ] Run build script
  ```bash
  ./build_macos_arm.sh  # For ARM64
  # OR
  ./build_macos_arm.sh Release universal  # For Universal Binary
  ```
- [ ] Build completed without errors
- [ ] Verify output files exist:
  ```bash
  ls -la "build/PRIResonanceSuppressor_artefacts/Release/AU/"
  ls -la "build/PRIResonanceSuppressor_artefacts/Release/VST3/"
  ```

## Verification Checklist

- [ ] Check plugin architecture
  ```bash
  # Should show "arm64" or "x86_64 arm64" for universal
  lipo -info "build/PRIResonanceSuppressor_artefacts/Release/AU/PRI Resonance Suppressor.component/Contents/MacOS/PRI Resonance Suppressor"
  ```
- [ ] Plugins built successfully:
  - [ ] AU component exists
  - [ ] VST3 bundle exists

## Installation Checklist

- [ ] Choose installation type:
  - [ ] System-wide (requires sudo, all users)
  - [ ] User-only (current user)

- [ ] Run installation script
  ```bash
  sudo ./install_macos.sh  # For system-wide
  # OR
  ./install_macos.sh  # Then choose option 2 for user-only
  ```

- [ ] Verify installation:
  ```bash
  # System-wide
  ls -la "/Library/Audio/Plug-Ins/Components/PRI Resonance Suppressor.component"
  ls -la "/Library/Audio/Plug-Ins/VST3/PRI Resonance Suppressor.vst3"
  
  # User-only
  ls -la "$HOME/Library/Audio/Plug-Ins/Components/PRI Resonance Suppressor.component"
  ls -la "$HOME/Library/Audio/Plug-Ins/VST3/PRI Resonance Suppressor.vst3"
  ```

- [ ] Remove quarantine attributes (important!)
  ```bash
  # System-wide
  sudo xattr -cr "/Library/Audio/Plug-Ins/Components/PRI Resonance Suppressor.component"
  sudo xattr -cr "/Library/Audio/Plug-Ins/VST3/PRI Resonance Suppressor.vst3"
  
  # User-only
  xattr -cr "$HOME/Library/Audio/Plug-Ins/Components/PRI Resonance Suppressor.component"
  xattr -cr "$HOME/Library/Audio/Plug-Ins/VST3/PRI Resonance Suppressor.vst3"
  ```
