📦 PREREQUISITES
─────────────────────────────────────────────────────────────────────────────
  1. macOS 11+ with Apple Silicon (M1/M2/M3)
  2. Xcode Command Line Tools:
     $ xcode-select --install
  3. CMake (via Homebrew):
     $ brew install cmake

🚀 BUILD & INSTALL (Simple)
─────────────────────────────────────────────────────────────────────────────
  $ ./build_macos_arm.sh
  $ sudo ./install_macos.sh

  That's it! The plugin will be available in your DAW after restart.

📝 BUILD & INSTALL (Step by Step)
─────────────────────────────────────────────────────────────────────────────
  1. Clone JUCE framework:
     $ git clone --depth 1 --branch 8.0.16-security \
       https://github.com/juce-framework/JUCE.git external/JUCE

  2. Configure build:
     $ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
       -DCMAKE_OSX_ARCHITECTURES=arm64

  3. Build plugin:
     $ cmake --build build --config Release

  4. Install AU (system-wide):
     $ sudo cp -r \
       "build/PRIResonanceSuppressor_artefacts/Release/AU/PRI Resonance Suppressor.component" \
       "/Library/Audio/Plug-Ins/Components/"

  5. Install VST3 (system-wide):
     $ sudo cp -r \
       "build/PRIResonanceSuppressor_artefacts/Release/VST3/PRI Resonance Suppressor.vst3" \
       "/Library/Audio/Plug-Ins/VST3/"

  6. Remove quarantine (important!):
     $ sudo xattr -cr "/Library/Audio/Plug-Ins/Components/PRI Resonance Suppressor.component"
     $ sudo xattr -cr "/Library/Audio/Plug-Ins/VST3/PRI Resonance Suppressor.vst3"

📍 PLUGIN LOCATIONS
─────────────────────────────────────────────────────────────────────────────
  After build:
    AU:   build/PRIResonanceSuppressor_artefacts/Release/AU/
    VST3: build/PRIResonanceSuppressor_artefacts/Release/VST3/

  After install (system):
    AU:   /Library/Audio/Plug-Ins/Components/
    VST3: /Library/Audio/Plug-Ins/VST3/

  After install (user):
    AU:   ~/Library/Audio/Plug-Ins/Components/
    VST3: ~/Library/Audio/Plug-Ins/VST3/

🎛️ USING THE PLUGIN
─────────────────────────────────────────────────────────────────────────────
  1. Restart your DAW
  2. Rescan plugins
  3. Look for "PRI Resonance Suppressor" by PRITEZZA
  4. Insert on a track with harsh frequencies
  5. Adjust LOW/HIGH to set frequency range
  6. Lower THRESHOLD until reduction appears
  7. Set DEPTH to taste (9-12 dB is typical)
  8. Use Δ LISTEN to hear what's being removed

⚙️ BUILD OPTIONS
─────────────────────────────────────────────────────────────────────────────
  Release build (ARM64):
    $ ./build_macos_arm.sh

  Debug build (faster compile):
    $ ./build_macos_arm.sh Debug

  Universal binary (Intel + ARM):
    $ ./build_macos_arm.sh Release universal

🔧 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────
  Plugin not showing in DAW?
    1. Rescan plugins in DAW preferences
    2. Restart DAW completely
    3. Remove quarantine:
       $ xattr -cr "/Library/Audio/Plug-Ins/Components/PRI Resonance Suppressor.component"

  Build errors?
    1. Check Xcode tools: xcode-select -p
    2. Update CMake: brew upgrade cmake
    3. Clean build: rm -rf build && ./build_macos_arm.sh

  CMake not found?
    $ brew install cmake
